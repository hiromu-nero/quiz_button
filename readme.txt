ひとまず僕のnoteを見た方がいいです。すべてが書いてあります。



動かないときは実行ファイルを、rmコマンドで取り除いてmakeし直すのがいい。
pip3 install gTTS
sudo apt update
sudo apt install mpg123
などはインストールした気がする、他にもあるかも。
それでも動かなかったら、スクショやソースコードをLLMに送ると解決してくれますよ!
ただし、あいつら平気で嘘をつくので、そのへんは頑張ってください。
無理な場合は周りのプログラム強い人に聞けばいいでしょう！



hannteiki
Arduinoのプログラムが入ってる。
Arduino nanoまたはその互換品に書き込んで使う。



Makefile
Makefile。なんとなく作ってるけど、使っていない。
しかもコンパイル後のファイルがあるので必要がない。



false.mp3
誤答のときのブザーの音。
音源は効果音ラボや、OtoLogicで拾ってきたものを使用しました。
再配布は良くなさそうなので、自分でとってきてください。



flag.mp3
ボタンを押したときの音。



quiz.csv
クイズの問題が入っているcsvファイルを準備してください。
「問題番号、問題文、回答」という順番で、１行目にはそのタイトルが入っているというフォーマットを守っていれば、任意の問題集でいける。
名前だけ「quiz.csv」じゃないとプログラム側の問題で認識されない。



quiz_buzzer
早押しボタンの実行ファイル。



quiz_buzzer.cpp
コンパイル前の早押しボタンのファイル。



quiz_system
早押しボタンが進化したやつの実行ファイル。
./quiz_systemのあとに、simpleと入力すると普通の早押しボタンとして、readと入力すると問読みモードとして、battleと入力すると対戦モードとして起動できる。
タイムカウント付き。
動かないなら、chmod +x quiz_systemかも。



quiz_system.cpp
コンパイル前の早押しボタン（進化版）のファイル。



slash.csv
スラッシュ付きの問題が入ったcsvファイルを準備してください。
スラッシュは半角だったはず。フォーマットを守れば（以下略）


ture.cp3
正解のときのブザー音。


プログラムを起動すると、いくつかmp3ファイルが生成されるが、問読みや答えに必要なだけなのであまり気にしなくていい。
